# Security Policy

Do not open public issues for suspected vulnerabilities. Report them privately to the repository
security contact configured by the publishing organization. Include affected versions, impact,
reproduction steps and any known mitigations. Do not include device credentials, owner tokens,
private file content or production URLs.

The maintainers will acknowledge a report within three business days, provide an initial severity
assessment within seven business days and coordinate disclosure after a fix is available.

Supported versions and the final reporting address must be set before the first public release.
Until then, this repository is an internal pre-release implementation.
